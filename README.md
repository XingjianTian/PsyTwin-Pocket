## 📖 项目简介

**PsyTwin-Pocket** 是 [PsyTwin](https://github.com/XingjianTian) **心图校园心理健康数字孪生解决方案**的**移动端入口**，定位为**轻量化、高频互动的心理健康陪伴工具**。

### 🎯 在生态系统中的位置

PsyTwin-Pocket 是 **PsyTwin 生态系统** 的前端触角，与 **Sentinel**（后端中台）、**Companion**（VR 边缘网关）、**OpenClaw**（AI 编排中心）协同工作，形成「**移动端日常感知 → 中台数据分析 → VR 深度干预 → AI 智能陪伴**」的完整闭环。

### 核心价值

> **「去标签化」**：让心理监测看起来像日常社交，让求助过程自然无压力。

通过多模态数据在数字世界中构建学生心理画像，实现从「手机端日常情绪感知」到「VR 端深度干预」的完整服务闭环。

#### 生态协作

- **Sentinel**: 提供帖子数据存储、NLP 情感分析、风险评分
- **OpenClaw**: 对帖子内容进行情感分析，识别高风险内容（规划中）
- **多模态数据**: 帖子浏览行为（停留时长、滑动速度）会被 Companion 采集，用于完善心理画像

#### 技术亮点

- **双列瀑布流算法**：使用贪心算法，根据预估卡片高度动态分配到较短的列，保持视觉平衡
- **虚拟列表优化**：只渲染可视区域卡片，大数据量下保持流畅
- **NLP 风险评估**：后端实时分析文本情感倾向，自动标记高风险内容

#### 文件位置

- `pages/home/index.js` - 首页逻辑（瀑布流算法、数据加载）
- `components/card/index.js` - 卡片组件（展示层）
- `api/post.js` - 帖子相关 API（对接 Sentinel）

#### 跨子项目数据流向

```
Pocket (行为数据)
    ↓
    • 页面停留时长
    • 帖子互动行为
    • AI 对话频次
    • 深夜活跃时段
    ↓

    ↓
    • 整合 Companion 的生理数据
    • 整合 OpenClaw 的情绪标签
    • 生成心理画像
    ↓

    • 我的页面显示四维度评分
    • 风险等级提醒
    • 个性化推荐
```

#### 心理画像模型

```json
{
  "studentId": "2023001001",
  "healthOverview": {
    "riskLevel": "low",           // 当前风险等级
    "riskScore": 0.15,            // 风险分数 (-1.0 ~ 1.0)
    "trend": "improving",         // 变化趋势
    "dimensions": [
      { "name": "情绪状态", "score": 82 },
      { "name": "睡眠质量", "score": 74 },
      { "name": "压力管理", "score": 68 },
      { "name": "社交关系", "score": 88 }
    ],
    "lastAssessment": "2026-03-15",
    "nextAssessment": "2026-03-29"
  }
}
```

#### 应用场景

- **日常监测**：通过 Pocket 端行为数据实时更新画像，数据流向 Sentinel → OpenClaw Analyst → Pocket
- **预警触发**：风险分数超过阈值时，Sentinel 自动通知教师端 (Sentinel Web)
- **干预建议**：OpenClaw Therapist 根据画像生成个性化干预方案，通过 Pocket 推送

2. **Sentinel** - 作为安全网关，验证身份、过滤敏感内容、记录日志
3. **OpenClaw Therapist** - 核心 AI 能力，提供心理治疗对话
4. **Sentinel (二次)** - 根据 AI 风险标记触发预警机制

#### 技术实现

```javascript
// api/ai.js - Pocket 端调用
export async function sendToTherapist(message) {
  // 通过 Sentinel 代理，而非直接调用 OpenClaw
  const response = await fetch('http://localhost:3000/api/openclaw/agent-chat', {
    method: 'POST',
    headers: { 
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${getToken()}`  // JWT 验证
    },
    body: JSON.stringify({
      agentId: 'Therapist',
      message,
      context: {
        studentId: getStudentId(),
        sessionId: getSessionId()
      }
    })
  });
  
  const data = await response.json();
  
  // 提取 AI 回复
  const reply = extractResponseText(data);
  
  // 检查风险标记
  if (data.riskLevel === 'high') {
    // 显示危机干预提示
    showCrisisIntervention();
  }
  
  return reply;
}
```

### 启动整个生态系统

如需启动完整的 PsyTwin 生态（开发环境），请按以下顺序：

```bash
# 1. 克隆所有仓库（假设在同一目录）
cd /Users/txj/Projects/PsyTwin

# 2. 启动 Companion (WebSocket Server)
cd PsyTwin-Companion/WebSocket-Server
docker-compose up -d

# 3. 启动 OpenClaw (AI 网关)
cd ../PsyTwin-OpenClaw
python -m openclaw.gateway

# 4. 启动 Sentinel (后端中台)
cd ../PsyTwin-Sentinel
npm install
npx prisma migrate dev
npm run dev

# 5. 启动 Pocket (微信小程序)
cd ../PsyTwin-Pocket
# 使用微信开发者工具导入项目
```

**依赖关系**:
- Companion → PostgreSQL, Redis
- Sentinel → PostgreSQL, Redis, Companion (可选), OpenClaw
- Pocket → Sentinel API
- OpenClaw → 无 (独立服务)

### 技术栈对比

| 层级 | Pocket (本仓库) | Sentinel | Companion | OpenClaw |

| **框架** | 微信小程序 | Next.js 16 | Node.js / FastAPI | FastAPI |
| **UI** | TDesign Mini Program | shadcn/ui + Tailwind | - | - |
| **数据库** | 无 (客户端) | PostgreSQL + Prisma | PostgreSQL + Redis | - |
| **实时通信** | - | SSE (Server-Sent Events) | WebSocket | WebSocket |
| **AI 能力** | 调用方 | 代理方 | ASR/TTS 集成 | Therapist/Analyst |
