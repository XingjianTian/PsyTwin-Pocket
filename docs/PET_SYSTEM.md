## 1. 系统概述

心宠系统是 PsyTwin-Pocket 中最复杂的模块，**3320 行代码**，提供虚拟心理伴侣功能，帮助学生建立情感连接、记录心理状态。

### 1.1 核心功能

```
┌─────────────────────────────────────────────────────────────┐
│                       心宠系统                              │
├──────────┬──────────┬──────────┬──────────┬─────────────────┤
│  游戏视图 │  世界地图 │   背包   │   日记   │     帮助        │
│ (主交互)  │ (场景切换)│ (物品管理)│ (记录回顾)│   (决策事件)    │
└──────────┴──────────┴──────────┴──────────┴─────────────────┘
```

### 1.2 技术特性

| 特性 | 说明 |
|------|------|
| **五视图切换** | game / map / bag / diary / help |
| **三维状态** | 心情 ❤️ / 能量 ⚡ / 社交 👥 |
| **精灵动画** | 45 帧循环动画，1fps |
| **24 个场景** | 5 个一级场景，24 个二级场景 |
| **WebSocket** | 实时状态同步，自动重连 |
| **AI 调度** | 自动行为决策，时段活动 |

## 2. 五视图架构

### 2.1 视图切换逻辑

```javascript
// pages/pet/index.js
Page({
  data: {
    currentView: 'game',  // 'game' | 'map' | 'bag' | 'diary' | 'help'
  },
  
  switchView(view) {
    this.setData({ currentView: view });
  },
});
```

### 2.2 视图说明

|------|------|----------|

| **help** | 帮助事件，决策影响状态 | `pages/pet/index.js` + `pages/pet/events/index` |

## 3. 三维状态系统

### 3.1 状态维度

| 维度 | 图标 | 范围 | 说明 |
|------|------|------|------|
| **心情** | ❤️ | 0-100 | 心宠的情绪状态 |
| **能量** | ⚡ | 0-100 | 心宠的体力值 |
| **社交** | 👥 | 0-100 | 心宠的社交欲望 |

### 3.2 状态警告

```
状态值 < 30: 显示红色警告
状态值 30-60: 显示黄色提醒
状态值 > 60: 显示正常绿色
```

### 3.3 状态影响因素

| 因素 | 影响 | 说明 |
|------|------|------|
| 场景切换 | 小幅波动 | 不同场景心情/能量变化不同 |
| 互动行为 | 正向增长 | 喂食、抚摸、对话 |
| 随机事件 | 正负波动 | 逃课 -10，观星 +15 |
| 时间流逝 | 自然衰减 | 长时间不互动状态下降 |
| 帮助决策 | 决策影响 | 不同选择影响不同维度 |

## 4. 精灵动画系统

### 4.1 动画帧

| 属性 | 说明 |
|------|------|
| **帧数** | 45 帧 |
| **帧率** | 1 fps |
| **格式** | PNG |
| **存放位置** | `static/pet/ExportedSprites/` |
| **文件数量** | 315 张（含 .meta 文件） |

### 4.2 动画实现

```javascript
// pages/pet/index.js
Page({
  data: {
    currentFrame: 0,
    totalFrames: 45,
  },
  
  onLoad() {
    this.startAnimation();
  },
  
  startAnimation() {
    this.animationTimer = setInterval(() => {
      this.setData({
        currentFrame: (this.data.currentFrame + 1) % this.data.totalFrames,
      });
    }, 1000);  // 1fps
  },
  
  onUnload() {
    clearInterval(this.animationTimer);
  },
});
```

### 4.3 精灵渲染

```xml
<!-- WXML -->
<image
  class="pet-sprite"
  src="/static/pet/ExportedSprites/frame_{{currentFrame}}.png"
  mode="aspectFit"
/>
```

### 4.4 CSS Fallback

当图片加载失败时，使用 CSS 绘制简单精灵：

```less
.pet-sprite {
  width: 200rpx;
  height: 200rpx;
  
  // 图片加载失败时的 fallback
  background: linear-gradient(135deg, #667eea, #764ba2);
  border-radius: 50%;
}
```

```javascript
// 切换场景
switchScene(sceneId) {
  this.setData({
    currentSceneId: sceneId,
    sceneBackground: `/static/scenes/${sceneId}.jpg`,
  });
  
  // 同步到服务端
  this.petSocket.send({
    type: 'scene_sync',
    data: { sceneId },
  });
}
```

## 9. 帮助事件系统

### 9.1 事件流程

```
1. 事件触发（随机或定时）
2. 显示事件卡片
3. 用户选择 4 个选项之一
4. 根据选择影响三维状态
5. 记录到日记
```

### 9.2 事件数据结构

```javascript
{
  id: 'event_001',
  title: '课间休息',
  description: '课间时间到了，心宠看起来有点累...',
  options: [
    { text: '让它休息', effects: { energy: +15, mood: +5 } },
    { text: '带它散步', effects: { energy: -10, social: +20 } },
    { text: '给它零食', effects: { energy: +10, mood: +10 } },
    { text: '不理它', effects: { mood: -10, social: -5 } },
  ],
}
```

### 9.3 决策影响

| 选择 | 心情 | 能量 | 社交 |
|------|------|------|------|
| 积极选项 | +5~+15 | +5~+15 | +5~+20 |
| 中性选项 | 0~+5 | -5~+5 | -5~+5 |
| 消极选项 | -5~-15 | -5~-10 | -5~-10 |

## 10. WebSocket 实时同步

### 10.1 连接配置

```javascript
// utils/petWebSocket.js
{
  url: 'ws://localhost:3001',  // 心宠服务地址
  reconnect: {
    strategy: 'exponential',  // 指数退避
    delays: [1000, 2000, 4000, 8000, 16000, 30000],
    maxRetries: 5,
  },
  heartbeat: {
    interval: 30000,  // 30 秒
    timeout: 10000,   // 10 秒超时
  },
}
```

### 10.2 消息类型

| 类型 | 方向 | 说明 |
|------|------|------|
| `pet_status` | S→C | 心宠状态更新 |
| `event_trigger` | S→C | 事件触发通知 |
| `scene_sync` | C→S | 场景同步 |
| `control_state_change` | C→S | 控制状态变更 |
| `heartbeat` | 双向 | 心跳保活 |

### 10.3 使用方式

```javascript
// pages/pet/index.js
import PetWebSocket from '../../utils/petWebSocket';

Page({
  onLoad() {
    this.petSocket = new PetWebSocket({
      url: getApp().config.petServiceUrl,
      onMessage: this.handleSocketMessage.bind(this),
    });
  },
  
  handleSocketMessage(message) {
    switch (message.type) {
      case 'pet_status':
        this.updatePetStatus(message.data);
        break;
      case 'event_trigger':
        this.showEventModal(message.data);
        break;
    }
  },
  
  onUnload() {
    this.petSocket.close();
  },
});
```

### 10.4 重连策略

```
第 1 次重连: 等待 1 秒
第 2 次重连: 等待 2 秒
第 3 次重连: 等待 4 秒
第 4 次重连: 等待 8 秒
第 5 次重连: 等待 16 秒
第 6 次及以后: 等待 30 秒
最多重试 5 次
```

## 11. AI 行为调度

### 11.1 调度系统概述

心宠具有自主 AI 行为系统，根据时段、场景、状态自动决策活动。

### 11.2 日程类型

| 类型 | 说明 |
|------|------|
| **工作日日程** | 周一至周五 |
| **周末日程** | 周六、周日 |

### 11.3 随机事件概率

| 事件 | 概率 | 说明 |
|------|------|------|
| 逃课 | 8% | 心情 +5，能量 +10 |
| 熬夜 | 15% | 心情 -5，能量 -15 |
| 观星 | 15% | 心情 +15，社交 +5 |
| 偶遇 | 12% | 社交 +20 |
| 发呆 | 20% | 心情 +3 |
| 正常活动 | 30% | 按日程执行 |

### 11.4 行为持续时间

| 类型 | 时长 | 说明 |
|------|------|------|
| **固定** | 40-60 分钟 | 上课、吃饭 |
| **半固定** | 20-30 分钟 | 运动、阅读 |
| **可变** | 5-15 分钟 | 散步、聊天 |

### 11.5 场景权重

不同场景有不同的活动权重分布：

| 场景 | 高权重活动 | 低权重活动 |
|------|-----------|-----------|
| 教室 | 学习、发呆 | 运动、社交 |
| 食堂 | 吃饭、社交 | 学习、休息 |
| 操场 | 运动、社交 | 学习、发呆 |
| 图书馆 | 学习、阅读 | 社交、运动 |
| 宿舍 | 休息、社交 | 学习、运动 |
