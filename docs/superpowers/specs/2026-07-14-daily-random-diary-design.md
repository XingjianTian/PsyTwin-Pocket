# 每日日记随机时间线设计

## 目标

打开心情日记后，当前日期必须能够直接展示一组从 Sentinel 日记模板库随机抽取的日记条目。生成不依赖心宠的 mood、energy、social、scene、当前时间或概率；同一天重复打开时保持同一组内容。

## 方案

Sentinel 新增“按日期确保日记时间线”的能力。Pocket 请求 `GET /api/pocket/pet/diary?date=YYYY-MM-DD&ensure=true`：

- 当天已有条目：直接返回已有条目，不重复生成；
- 当天没有条目：从模板库随机抽取 4—8 条，生成 08:00—23:00 之间的互不重复时间点，按时间排序并持久化；
- 条目正文、标题来自模板库；
- 条目不读取心宠实时状态，`mood`、`energy` 置为空，场景标记为 `daily`；
- 仍返回 `entries` 与 `diaryDataMap`，保持 Pocket 当前展示结构兼容。

Pocket 在进入日记视图和选择日期时使用 `ensure=true`，接口失败时保留本地已有数据并显示空状态；测试按钮继续调用测试接口。

## 组件与数据流

1. Sentinel `pet-diary-core`：提供批量数量、唯一随机时间和模板抽取的纯函数。
2. Sentinel `pet-diary-service`：查询日期已有记录；为空时批量创建；统一映射返回结构。
3. Sentinel GET 日记路由：解析 `ensure` 查询参数并调用服务层。
4. Sentinel API 契约：记录 `ensure` 参数和批量返回语义。
5. Pocket API/页面：读取当天或选中日期时传 `ensure=true`。

## 验收标准

- 日记页面首次打开当天无记录时，能展示至少 4 条时间线条目。
- 条目时间排序升序且当天时间不重复。
- 重复打开同一天不会新增条目。
- 切换到无记录日期时能自动生成并展示该日期条目。
- 生成结果只来自模板库，不依赖心宠三维状态、场景、时间或随机触发概率。
- Sentinel 单元测试与 Pocket 相关 lint/验证通过；已有功能不受影响。
