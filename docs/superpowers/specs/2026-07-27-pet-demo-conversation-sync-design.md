# F9 三端心宠对话同步设计

> 设计日期：2026-07-27

## 目标

F9 演示从“户外场景直接切换咨询室”扩展为“户外相遇、两句对话、切换心理咨询室”。服务器继续是唯一时间轴，Pocket、Sentinel 和 Unity 消费同一 `pet_status`。

## 验收状态

- [x] 服务器切入户外时立即广播 `line_1`，再广播 `line_2` 并切入 `psychological_room`，避免客户端加载期间错过主心宠台词。*(已于 2026-07-27 通过服务端自动化测试)*
- [x] Unity、Pocket 与 Sentinel 均未连接时 F9 仍可启动服务器演示，后续连接的客户端可读取当前阶段。*(已于 2026-07-27 通过服务端无客户端回归测试)*
- [x] Pocket 在户外隐藏普通主心宠与所有随机心宠，仅在左侧显示花环完整立绘的小暖、右下显示放大的水手服主心宠，并使用 F9 专属大对话框。*(已于 2026-07-27 通过结构回归测试)*
- [x] 页面启动时不再显示旧的 CSS 圆脸心宠；主心宠动画继续使用 `static/pet/ExportedSprites` 序列帧，改为隐藏层加载完成后再切换的双缓冲渲染。*(已于 2026-07-27 通过结构回归测试)*
- [x] F9 对话为排他模式：进入时清理旧的随机对话，演示期间禁止日常心宠对话定时器改写主心宠气泡。*(已于 2026-07-27 通过结构回归测试)*
- [x] F9 台词与顺序固定，小暖回复阶段保留 4.8 秒后才切换心理咨询室，不从日常随机对话库取值。*(已于 2026-07-27 通过服务端时序与台词回归测试)*
- [x] 提供 Pocket、Sentinel、Unity 三端完整配置、联调顺序与常见故障排查文档。*(已于 2026-07-27 写入 `docs/F9_DEMO_SYNC_SETUP.md`)*
- [x] Sentinel 学生心宠页面同步显示两只完整心宠和台词，小暖统一使用 `pet-06.png` 花环立绘。*(已于 2026-07-27 完成实时状态接线)*
- [x] Unity 使用新增的普通 `MonoBehaviour` 独立脚本；挂载到目标场景后，在 Inspector 中为主心宠台词与小暖台词分别拖入 `TMP_Text` 引用，运行时立即连接服务器同步台词。*(已于 2026-07-27 完成可手动配置脚本)*
- [x] 主心宠按素材有效内容区域校准尺寸，在 Pocket 演示模式、Pocket 日常生活和 Sentinel 观察页中均与小暖保持接近的视觉大小。*(已于 2026-07-27 完成三处尺寸统一并通过回归测试)*
