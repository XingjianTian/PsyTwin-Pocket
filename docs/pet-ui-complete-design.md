## 一、概述

### 1.1 模块定位

心宠（Pet）模块是 PsyTwin-Pocket 小程序的核心功能之一，为用户提供虚拟宠物养成体验。通过心宠的状态变化反映用户的心理健康状况，提供心理陪伴与情绪疏导功能。

### 1.2 页面结构

```
┌─────────────────────────────────────────────┐
│                心宠主页 (Tab)                 │
│            pages/pet/index                  │
├─────────────────────────────────────────────┤
│                                             │
│   ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│   │ 世界地图 │  │ 求助事件 │  │  心宠背包 │   │
│   └─────────┘  └─────────┘  └─────────┘   │
│                 │                             │
│                 ▼                             │
│          ┌─────────┐                         │
│          │ 心情日记 │                         │
│          └─────────┘                         │
│                                             │
└─────────────────────────────────────────────┘
```

### 1.3 设计理念

- **沉浸感**: 全屏沉浸式背景，UI 元素悬浮于场景之上
- **治愈性**: 玻璃拟态效果，柔和的色彩与动画
- **一致性**: 所有页面采用统一的视觉语言与交互规范
- **情感化**: 通过心宠状态反映用户心理状态

## 五、世界地图设计（模态覆盖式）

> **更新说明**：世界地图采用**模态覆盖式**设计，而非独立页面跳转。点击世界地图按钮后，地图以浮层形式覆盖在游戏界面之上，主界面背景保持可见，形成"在游戏内打开地图"的沉浸式体验。

### 5.1 交互设计规范

#### 5.1.1 触发与关闭

**触发方式**：
- 点击功能面板中的「世界地图」按钮（🗺️）

**关闭方式**（三选一）：
1. 点击地图外部的遮罩区域
2. 点击地图左上角的「×」关闭按钮
3. 按下 Escape 键（物理键盘设备）

**禁止行为**：
- ❌ 使用 wx.navigateBack 关闭（不是页面）
- ❌ 单独设计返回按钮

#### 5.1.3 尺寸与位置

| 参数 | 值 | 说明 |
|------|-----|------|
| **宽度** | 90% 屏幕宽度 | 最大 680rpx |
| **高度** | 自适应内容 | 最小 600rpx，最大 85% 屏幕高度 |
| **位置** | 水平居中，垂直居中 | `position: fixed` |
| **圆角** | 32rpx | 顶部和底部圆角 |
| **z-index** | 200 | 高于遮罩层 |
| **遮罩 z-index** | 150 | 低于地图，高于游戏界面 |

#### 5.1.4 动画规格

**入场动画**：
```
0ms     → 遮罩淡入 (opacity 0→0.4, 250ms, ease-out)
50ms    → 地图从底部滑入 (translateY 100%→0, 350ms, cubic-bezier(0.4, 0, 0.2, 1))
```

**出场动画**：
```
0ms     → 地图向下滑出 (translateY 0→100%, 250ms, ease-in)
100ms   → 遮罩淡出 (opacity 0.4→0, 200ms, ease-out)
```

#### 5.1.5 背景游戏区域状态

当地图打开时：
- **Canvas 游戏区域**：保持渲染，但添加轻微模糊效果（`filter: blur(2px)`）或降低不透明度（`opacity: 0.6`）
- **功能面板 Dock**：降低不透明度（`opacity: 0.5`），表示不可操作
- **状态栏**：保持正常显示，不受影响

#### 5.4.3 JS 控制逻辑

```javascript
// pages/pet/index.js

// 世界地图显示状态
data: {
  showMap: false,
}

// 打开世界地图
openWorldMap() {
  this.setData({ showMap: true });
  // 可选：暂停 Canvas 动画或添加模糊效果
  this.pauseCanvasAnimation();
}

// 关闭世界地图
closeWorldMap() {
  // 先执行出场动画
  this.setData({ showMap: false });
  // 可选：恢复 Canvas 动画
  this.resumeCanvasAnimation();
}

// 点击地块
onSceneTap(e) {
  const { scene } = e.currentTarget.dataset;
  // 显示场景详情弹窗
  this.setData({ selectedScene: scene, showSceneModal: true });
}
```

背景图需要适配竖向全屏，UI 元素悬浮在上方：

```

│                                 │
```

- 底部区域（约 20%）相对简洁，避免被按钮面板遮挡

## 七、动效设计

### 7.1 入场动画

```
时间线：
0ms    → 背景图淡入（300ms）
200ms  → 状态栏从上滑入 + 淡入（400ms, ease-out）
400ms  → 心宠精灵缩放出现（500ms, elastic）
600ms  → 按钮面板从下弹入（400ms, spring）
800ms  → 粒子特效开始出现
```

### 7.2 持续动画

| 元素 | 动画 | 参数 |
|------|------|------|
| 心宠精灵 | 呼吸 | scale(1.0 ↔ 1.05), 2s, ease-in-out, infinite |
| 心宠精灵 | 漂浮 | translateY(0 ↔ -10rpx), 3s, ease-in-out, infinite |
| 粒子 | 飘落 | translateY(-100rpx → 100vh), 8-15s, linear, infinite |
| 虚拟宠物 | 浮动 | translateY(0 ↔ -5rpx), 4s, ease-in-out, infinite |
| 气泡文字 | 淡入淡出 | opacity(0 → 1 → 0), 4s, ease-in-out |

### 7.3 交互反馈

| 交互 | 反馈 |
|------|------|
| 点击按钮 | 缩放至 0.9，内凹阴影，150ms 回弹 |
| 点击心宠 | 心宠跳跃 + 爱心粒子爆发 |
| 状态变化 | 进度条平滑过渡，发光闪烁 |
| 场景切换 | 背景图交叉淡入淡出 500ms |

| 参数 | 要求 |

| **格式** | PNG（带透明背景）或 JPG |
| **风格** | 扁平插画 / 轻度厚涂 / 治愈系 |
| **色调** | 低饱和度，暖色调，羊皮纸质感 |

### 8.3 构图要求（背景图）

- **顶部 20%**：相对简洁，天空/天花板区域，避免复杂元素（会被状态栏遮挡）
- **中间 60%**：视觉焦点，可放置丰富细节和主体元素

- 整体色调低饱和度，治愈系风格

- 图片使用 `mode="aspectFill"` 填充场景容器
- Canvas 在背景图之上绘制动态元素（心宠精灵、虚拟宠物）
- 场景切换时背景图淡入淡出过渡（300ms）
- 毛玻璃效果使用 `backdrop-filter: blur(20px)`
