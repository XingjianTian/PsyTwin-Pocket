# PRD: PsyTwin Pocket 教师端功能规格说明书

> 最后更新: 2026-03-06
> 文档状态机：`- [x]` 已实现 / `- [ ]` 待开发 / `⚠️` 部分实现

---

## 文档说明

本文档定义 PsyTwin Pocket 教师端（心理咨询师/心理教师）功能规格。教师端与学生端共用以下模块：
- **心墙**：浏览校园动态（与学生端一致）
- **AI**：AI 对话与消息通知（与学生端一致）

教师端特有模块：
- **工作台**：教师日常工作核心功能
- **我的**：教师个人信息与功能入口（与学生端有差异）

---

## 1. 模块一：工作台 (Workbench)

### 1.1 页面定位
- **功能**：心理咨询师日常工作仪表盘
- **形态**：数据看板 + 快捷操作 + 待办提醒
- **定位**：一站式处理预警响应、学生咨询、排班管理

### 1.2 核心功能

#### 1.2.1 预警看板 ⭐ 核心功能
- **功能**：实时展示学生心理健康预警列表
- **状态**：`- [ ]` 待开发
- **优先级**：高

| 预警级别 | 颜色标识 | 触发条件 | 响应动作 |
|---------|---------|---------|---------|
| 高风险 | 🔴 红色 | 自杀/自伤关键词、情绪分数<-0.8、连续3天负面 | 立即介入 + 上报 |
| 中风险 | 🟠 橙色 | 持续负面情绪、情绪分数<-0.5、周活跃度下降50% | 主动关注 + 预约 |
| 低风险 | 🟡 黄色 | 情绪波动、轻微负面倾向 | 记录观察 |

**预警列表项字段：**
```javascript
{
  id: String,
  studentId: String,
  studentName: String,
  avatar: String,
  riskLevel: 'high' | 'medium' | 'low',
  riskReason: String, // 触发原因简述
  triggerSource: 'chat' | 'post' | 'assessment' | 'behavior',
  triggeredAt: String, // ISO时间
  status: 'pending' | 'processing' | 'resolved',
  assignedTo: String, // 负责老师ID
  lastAction: {
    type: 'call' | 'message' | 'appointment' | 'note',
    content: String,
    time: String
  }
}
```

**交互流程：**
```
进入工作台 → 顶部显示预警统计卡片（高/中/低各数量）
     ↓
点击预警列表 → 查看学生档案 + 触发详情
     ↓
选择响应动作：电话联系 / 发送消息 / 预约咨询 / 记录备注
     ↓
标记处理状态：待处理 → 处理中 → 已解决
```

**UI设计：**
- 顶部横向滚动预警卡片（仅显示高风险、最新5条）
- 下方列表展示全部预警，支持按级别筛选
- 红点提醒：未读高风险预警

## 6. 建议开发顺序

### 阶段一：工作台 MVP（优先级：高）
1. 预警看板基础列表（仅展示，可先mock数据）
2. 今日日程卡片
3. 快捷入口（跳转占位页面）
4. 数据统计调整为教师个人维度

### 阶段二：核心业务流程（优先级：高）
1. 预警详情页 + 处理流程
2. 学生档案列表 + 搜索
3. 预约管理列表 + 基础操作

### 阶段三：完善功能（优先级：中）
1. 排班管理（时间设置）
2. 预警规则配置
3. 消息通知设置

### 阶段四：优化体验（优先级：低）
1. 数据报表图表化
2. 推送通知（新预警提醒）
3. 离线缓存
