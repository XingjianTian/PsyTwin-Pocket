## 快速导航

### 产品需求 (`pet-product-design.md`)
- **第1章** — 产品概述（定位、核心理念、生态关系）

- **第4章** — UI 设计规范（色彩系统、字体规范、动画规范、组件风格）

### API契约 (`pet-api-contract.md`)
> Pocket 是 API 消费方，需要调用 Pet 服务端提供的所有接口

- **第2章** — 基础规范（Base URL、请求头、统一响应格式、错误码）
- **第3章** — HTTP API 接口：
  - `3.1` 心宠状态（GET /status、POST /create）
  - `3.2` 场景管理（GET /scenes、POST /scenes/:id/enter）
  - `3.3` 事件系统（GET /events/pending、POST /events/:id/resolve）
  - `3.4` 日记系统（GET /diary）
  - `3.5` 背包系统（GET /inventory）
- **第4章** — WebSocket 消息协议（连接流程、认证、心跳、状态推送、场景同步、事件触发、控制权变更）
- **第5章** — SSE 场景广播协议（Phase 2）

### UI设计总览 (`pet-ui-complete-design.md`)
- **第1章** — 概述（模块定位、页面结构、设计理念）
- **第2章** — 设计系统（色彩、毛玻璃、新拟态、字体、阴影规范）
- **第3章** — 主页布局与设计（状态栏、场景区、功能面板）
- **第4章** — 子页面UI设计（地图、事件、背包、日记）
- **第5章** — 世界地图设计（5地块、路径、装饰元素）
- **第6章** — 场景背景图设计（4个场景详细规格）
- **第7章** — 动效设计（入场、持续、交互反馈）
- **第8章** — 技术规格
- **第9章** — 文件交付清单
