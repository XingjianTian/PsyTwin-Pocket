## 快速导航

### 如果你是新加入的开发者

```
1. 阅读 PROJECT_OVERVIEW.md 了解项目全景
2. 阅读 DEVELOPMENT_SETUP.md 搭建开发环境
3. 阅读 API_GUIDE.md 和 COMPONENT_GUIDE.md 了解开发规范
4. 开始开发！
```

### 如果你要开发心宠功能

```
1. 阅读 PET_SYSTEM.md 了解心宠系统架构
2. 阅读 pet_schedule_analysis.md 了解 AI 调度逻辑
3. 参考二级场景AI生图描述.md 了解美术规范
```

### 如果你要对接后端接口

```
1. 阅读 API_GUIDE.md 了解请求层规范
2. 查看 api/ 目录下的接口模块
3. 遵循契约规范，不脑补字段
```
