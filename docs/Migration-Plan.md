## 5. 技术决策

### 5.1 目录策略

- 保留当前小程序目录不动
- 桌面端使用独立 `desktop/` 子工程
- 共享逻辑先在桌面端内部收敛，稳定后再考虑抽 `shared/`

### 5.2 UI 策略

- 优先保持原有信息架构、功能路径和视觉层级
- 桌面端展示为固定手机画布，不做大屏桌面化改造
- 尽量还原小程序的间距、圆角、底部导航、卡片比例和主色体系
- 能用自定义样式还原的部分，优先不用桌面组件默认外观替代

### 5.3 数据策略

- 首版默认保留 Mock 演示能力
- 真实 API 作为第二运行模式保留
- 请求层统一经 `services/http.js`
