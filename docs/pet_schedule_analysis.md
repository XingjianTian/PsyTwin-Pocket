# 心宠时间调度系统分析

## 概述

心宠的行为基于**现实时间**进行调度，每小时检查一次场景切换。系统分为**工作日**（周一到周五）和**周末**（周六到周日）两套日程，并叠加了**随机事件**机制，让心宠的行为更加自然和不可预测。

---

## 场景分类体系

### 按功能分类

| 类别 | 场景 | 说明 |
|------|------|------|
| **休息区** | 卧室(bedroom)、宿舍(dormitory) | 睡觉、休息、娱乐 |
| **学习区** | 教学楼(teaching_building)、图书馆(library) | 上课、自习、阅读 |
| **餐饮区** | 食堂(cafeteria)、厨房(kitchen) | 用餐、烹饪 |
| **运动区** | 操场(playground) | 锻炼、运动 |
| **奇幻空间** | 魔法森林(deep_forest)、水晶洞穴(crystal_cave)、蘑菇村落(mushroom_village)、精灵湖泊(fairy_lake)、星空草地(star_meadow) | 探险、魔法、自然 |
| **自由旷野** | 篝火区(bonfire_area)、野餐草坪(picnic_lawn)、吊床区(hammock_area)、溪流边(stream_side)、观景台(viewing_platform) | 户外、休闲、社交 |
| **小镇** | 超市(supermarket)、电影院(cinema)、游乐园(amusement_park)、咖啡馆(cafe)、游戏厅(arcade) | 购物、娱乐、社交 |
| **梦境小屋** | 书房(study_room)、厨房(kitchen)、花园(garden) | 居家、阅读、园艺 |
| **心理支持** | 心理咨询室(psychological_room) | 咨询、放松 |

### 按行为持续时间分类

| 类型 | 场景 | 持续时间 | 特点 |
|------|------|----------|------|
| **固定场景** | 教学楼、图书馆 | 40-60分钟 | 期间行为不变（如上课） |
| **半固定场景** | 食堂、心理咨询室 | 20-30分钟 | 持续时间中等 |
| **可变场景** | 其他所有场景 | 5-15分钟 | 行为可频繁变化 |

| **08:00-11:00** | 教学楼 🏫 | 教学楼(75-85%) + 图书馆(10-15%) + 卧室(5-10%) | **上课时间**，偶尔翘课在宿舍 |
| **12:00** | 食堂 🍜 | 食堂(70%) + 野餐草坪(20%) + 蘑菇村落(10%) | **午餐时间** |
| **13:00-16:00** | 图书馆 📚 | 图书馆(45-55%) + 教学楼(20-35%) + 操场/吊床(10-20%) | **下午自习**，偶尔去操场运动 |

## 随机事件系统

除了正常的时间调度，心宠还有概率触发**随机事件**，偏离正常日程：

| 事件名称 | 触发概率 | 可能场景 | 说明 |
|----------|----------|----------|------|
| **逃课探险** | 8% | 魔法森林、水晶洞穴、蘑菇村落、精灵湖泊 | 不去上课，去奇幻空间探险 |
| **熬夜游戏** | 15% | 卧室、宿舍 | 深夜不睡觉，打游戏 |
| **早起探险** | 12% | 魔法森林、水晶洞穴 | 比平时早起去探险 |
| **突发看电影** | 10% | 电影院、游戏厅、游乐园 | 突然想去娱乐 |
| **半夜觅食** | 8% | 食堂、厨房 | 半夜起来找吃的 |
| **观星** | 15% | 星空草地、观景台 | 晚上去看星星 |

### 随机事件影响

- 触发后会**覆盖**正常的时间调度
- 让心宠行为更真实、不可预测
- 用户可能会发现心宠在"不该出现"的地方

## 场景切换机制

### 整点检查
- 每小时检查一次是否需要切换场景
- 基于当前小时的权重配置随机选择

### 行为持续时间
- **固定场景**（教学楼、图书馆）：40-60分钟
- **半固定场景**（食堂、心理咨询室）：20-30分钟
- **可变场景**：5-15分钟

### 切换逻辑
```
1. 根据当前时间获取应该去的场景（按权重随机）
2. 检查是否触发随机事件（偏离日程）
3. 如果目标场景和当前相同，检查行为持续时间是否已到
4. 如果持续时间已到，随机选择新行为（同一场景内）
5. 更新场景和活动描述
```

## 关键观察

1. **心宠是"学生"设定**：工作日以学习为主（教学楼+图书馆），周末以休闲为主（奇幻空间+小镇）
2. **睡眠时间固定**：00:00-07:00以卧室为主，符合学生作息
3. **三餐时间明确**：12:00和18:00以食堂为主
4. **周末更自由**：周末上午可能还在睡觉（bedroom权重25%），也可能早起探险
5. **随机事件增加趣味性**：15%概率熬夜游戏、8%概率逃课，让心宠更像真实学生
6. **场景层次丰富**：从现实场景（教学楼、食堂）到奇幻场景（魔法森林、精灵湖泊），满足不同情绪需求
